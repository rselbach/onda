# Public commands of onda_app::App that the Linux shell does not call.
# `cargo test -p onda-linux --test core_parity` compares this list with the code.
#
# When you start calling a command, delete its line. A new core command needs
# a call under shell/linux/src or a line here before the test passes.
#
# <command> #<issue that will call it> [note]
# <command> never <why Linux never needs it>

begin_hotkey_capture             never the record button toggles the capture, as on macOS
fix_permission                   never Linux has no privacy permission to fix
flush_events                     never a barrier for the core's own tests
onboarding_use_clipboard         never the link sits on the Permissions step, which Linux does not have
open_keyboard_settings           never it sits next to the Fn warning, and Linux has no Fn shortcuts
open_login_items                 never Linux autostart needs no approval, so the caption never offers it
set_hotkey                       never the recorder commits the shortcut inside the core, as on macOS
settings_changed                 never the shell changes settings only through core commands
shutdown                         never the shell owns the runtime and calls shutdown_async
start                            never the shell owns the runtime and calls start_on
